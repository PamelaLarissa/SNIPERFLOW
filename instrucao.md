# Segue instrução de Iniciação do sistema para desenvolvimento:
- ctrl + J = Abrir o terminal
OBS: Precisa estar na aba terminal. Haverá 5 abas sendo elas: 
- Problemas
- Saída
- Console de Depuração
- Terminal 
- Portas 
## Certifique de estar na aba Terminal para iniciar o sistema

1º Iniciar o backend: 
# Dentro do temrinal você precisa navegar até o diretório backend e iniciar o servidor com o comando: 

- cd backend (esse comando faz você navegar até o diretório backend)
- npm run dev (esse comando inicia o servidor/backend)

# Agora você precisa abrir outro terminal. Esse outro terminal servirá para você iniciar o frontend

OBS: Para abrir outro terminal você precisa apertar no simbolo de + que está do lado direito do terminal, depois das 4 abas
## Assim que apertar o botão de + outro terminal será aberto e você já estará na raiz do projeto então basta você inserir o comando para iniciar o frontend

- npm run dev 

Prontinho. Dessa maneira o seu sistema está rodando tando o backend quanto o frontend em dois terminais distintos.
